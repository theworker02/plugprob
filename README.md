# plugprob

Plug lightweight prob statistics from stdin samples.

**Site:** https://theworker02.github.io/plugprob/

## Install / run

```bash
git clone https://github.com/theworker02/plugprob.git
cd plugprob
node src/cli.js
node --test
```
